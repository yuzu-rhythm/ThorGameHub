# 公開前の点検

点検日: 2026-10-23。公開専用コピーを使用し、元プロジェクトのソース、設定、実機データを変更していません。

## 対象と方法

公開予定の全テキストを、秘密鍵・APIトークンの形式、メール、個人パス、個人ハンドル、私有サービスURL、プライベートIP等のパターンで検索しました。検出結果をレビューし、バイナリは別途確認しています。Gradle WrapperのJARは公式SHA-256と一致しました。画面例は新規の使い捨てエミュレータで撮影し、実装内の架空タイトルとの一致と画像を目視確認しました。

## 結果

- 公開用ソースでは認証情報・個人識別情報に該当するパターンは検出していません。
- Gradle Wrapper以外の依存ライブラリ本体や外部アプリを同梱していません。
- 5件のJSONはRoomのスキーマであり、SQLiteの実データではありません。
- 初期表示は `FixtureSeeder` による架空のゲーム情報です。ROM・BIOS・ゲーム画像や個人の履歴をコピーしていません。
- 元フォルダに `.git` はなく、引き継ぐGit履歴はありません。公開用には新しいGitリポジトリを構築します。
- 原本に存在する大きなbuildフォルダには端末由来のSQLite・ログ・画面・外部アプリのAPK等があるため、ファイルを指定してコピーし、build以下を一切持ち込んでいません。

## 除外対象

元の全build出力、APK、外部アプリ、端末ログ、SQLite / WAL / SHM、診断出力、セーブ、実機・旧エミュレータのスクリーンショット、UIダンプ、Gradle/Kotlinキャッシュ、IDE設定、個人SDKパス、署名鍵、内部プロンプト、運用・実機確認の原資料を公開対象から除外しました。

ローカルAVD名を含む旧エミュレータ一括検証スクリプトも除外しました。公開用 `scripts/verify.sh` はホスト検証専用にして、Connectedテストを要求された場合はADBへ到達する前に終了します。`clean` は公開用コピーの生成物に対してのみ実行しました。

`.gitignore` はbuild、APK、DB、秘密鍵、署名設定、診断・保存データなどを除外します。実際の公開ファイル一覧は `PUBLIC_FILES.txt` を参照してください。

## 限界

パターン検査とレビューであり、未知の形式の秘密情報や全コードの第三者由来まで保証する監査ではありません。署名・製品版配布・実機の保存データ・外部ゲームの動作は今回未検証です。ファイル追加後は再点検が必要です。この点検を終えた時点ではGitHub上の作成・push・公開範囲変更は未実施でした。その後の登録状況はGitHubの設定を参照してください。
