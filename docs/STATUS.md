# 実装と検証の範囲

2026-10-23公開用スナップショット。

| 項目 | コード上の状態 | 今回の証拠・残る確認 |
| --- | --- | --- |
| ライブラリ・メモ・セッション | 実装あり | JVMテスト、ビルド、エミュレータの初期画面 |
| Roomスキーマ・Migration | 実装あり、v1〜v5 | Androidテストのコンパイル。接続テストは今回未実施 |
| 表示の動的検出・Companion | 実装あり | ホストテスト。Thorの上下パネルは未確認 |
| SAF・アクセス権・照合 | 実装あり | ホストテストとコンパイル。実プロバイダの操作は未確認 |
| 外部ゲーム起動 | アダプタ実装あり | 実タイトルの起動・配置・終了は未確認 |
| 保存先のsnapshot / restore | ローカル実装あり | ホストテスト。実ゲームのセーブ互換性・復元は未確認 |
| 大文字・フォーカス・入力 | 実装あり | ホストテストと単画面表示例。Thorの物理入力は未確認 |
| クラウド / PC同期 | ローカルtransport契約のみ | ネットワーク同期は未実装 |
| 特権ブリッジ | capability境界のみ | 有効なroot / Shizuku等の特権操作は未実装 |
| 蓋イベントの識別 | UNKNOWNを保持 | 画面状態の変化から蓋開閉を推定しない |
| アプリ内スクリーンショット取得 | 未有効化 | MediaProjection等の実機確認が必要 |
| 製品版配布 | 未実施 | debug版候補。リリース署名・製品品質の認定なし |

過去の記録には別のAPKを使ったエミュレータ・一部実機確認が含まれますが、この公開用コピーの再検証とは分けて扱っています。今回のAPKの実機成功や全機能の完成を主張しません。
